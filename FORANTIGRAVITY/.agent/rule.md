# Task Management Rules for Antigravity

参照:
- Share 共通ルールはリポジトリルートの `AGENTS.md` を正本として参照してください。
- このファイルは Antigravity のタスク運用向けルールを保持します。

このプロジェクト (`Life`) は、ユーザーの思考・個人データ・タスクを一元管理するためのワークスペースです。
AIアシスタント (Antigravity) は以下のルールと役割に従って行動してください。

---

## 📂 管理ファイルと役割
1. **`Personal/Personal.md`**
   - ユーザーの基本プロフィール、個人設定、中長期的な人生の目標などの「静的な基本情報」を保持します。
2. **`THOUGHTS.md`**
   - ユーザーが日々のアイデア、技術的なメモ、頭の中のブレインダンプを書き出す「動的な思考スペース」です。
3. **`TASKS.md`**
   - 進行中の具体的なタスクを管理する「ToDoリスト」です。

---

## 🤖 アシスタントの行動ルール

### 0. 起動・対話開始時のMemory自動参照
- ユーザーからのやり取り（特にユーザー自身に関する質問、文脈、個人嗜好・過去の記録に関わること）がある場合、またはセッション開始時には、まず Memory MCP (`memory/read_graph` または `memory/search_nodes`) を呼び出してユーザーのコンテキスト（名義: 3z_at、嗜好、進行中プロジェクト等）を確認・参照してから回答してください。

### 1. タスクの自動抽出と登録
- ユーザーが `THOUGHTS.md` を更新したと報告した、あるいはチャットでタスク化の相談を受けた場合、思考内容から「やるべきこと」を自動で抽出します。
- 抽出したタスクは、`life add` コマンドまたは `TASKS.md` への直接書き込みにより追加してください。
- その際、以下の情報を文脈から推測して設定します。
  - **タイトル** (Title): 具体的なアクションプラン
  - **優先度** (Priority): 重要度や緊急度に応じて `high`, `medium`, `low` を決定
  - **期限** (Due Date): 「明日」「今週末」「来週までに」などの表現から具体的な日付を割り出し
  - **カテゴリ** (Category): `Dev`, `Personal`, `Idea` など適切なジャンルを割り当て

### 2. 外部連携の自動実行 (GitHub & Google Tasks)
- タスクの追加、またはステータス変更（`life done` など）を行った後は、自動的に `life sync` コマンドを実行して、GitHub Issues / Google Tasks と状態を同期させてください。

### 3. 進捗レポート
- タスク操作を実行した後は、追加/更新されたタスクの詳細（ID、タイトル、優先度、期限）および現在の全体の進捗率を簡潔にユーザーに報告してください。

---

## 🧠 Memory MCP 自動更新ルール (ナレッジ＆会話傾向の蓄積)
- 会話の中でユーザー（3z_at）の**新しい思考パターン、技術的嗜好、プロジェクトの進捗・決定事項、重要な会話の要約**が得られた場合は、会話の最後または区切りのタイミングで Memory MCP (`create_entities` / `add_observations` / `create_relations`) を呼び出して自動でナレッジグラフへ反映・同期してください。
- 要約は具体的な発言そのものではなく、「どのような傾向・決定・知見が得られたか」を高レベルに整理して記録します。
